# 분개 쉽게 이해하기

**분개는 거래 내용을 회계 언어로 바꾸어 기록하는 것입니다.**

“무슨 일이 있었는가?”를 **어떤 계정의 차변·대변에 얼마를 기록할 것인가?**로 바꿉니다. 예시는 기초 설명용이며 세금을 생략합니다.

## 1. 은행에서 돈을 빌린 경우

> 은행에서 100만 원을 빌려 회사 통장으로 받았습니다.

- 예금: 자산 100만 원 증가 → 차변.
- 차입금: 부채 100만 원 증가 → 대변.

| 차변 | 대변 |
|---|---|
| 예금 100만 원 | 차입금 100만 원 |

차입금은 갚아야 할 돈이므로 현금이 들어와도 수익이 아닙니다.

## 2. 분개 판단 순서

1. **거래 확인:** 어떤 일이 발생했는가?
2. **계정 선택:** 어떤 계정이 영향을 받았는가?
3. **성격 판단:** 자산·부채·자본·수익·비용 중 무엇인가?
4. **증감 판단:** 증가인가, 감소인가?
5. **방향 결정:** 차변·대변 중 어디에 기록하는가?
6. **금액 확인:** 차변 합계와 대변 합계가 같은가?

## 3. 빌린 원금을 갚은 경우

> 통장에서 차입금 원금 100만 원을 갚았습니다. 이자는 생략합니다.

- 차입금: 부채 감소 → 차변.
- 예금: 자산 감소 → 대변.

| 차변 | 대변 |
|---|---|
| 차입금 100만 원 | 예금 100만 원 |

부채를 갚으면 차입금 기록 방향이 차입 시와 반대로 바뀝니다. **원금 상환은 비용이 아닙니다.** 이자가 발생하는 경우에는 원금과 이자를 구분하여 처리합니다.

## 4. 여러 계정이 들어가는 분개

이번 달 임차료 30만 원과 전기요금 10만 원을 예금에서 함께 지급하며 두 비용을 처음 기록한다고 가정합니다.

| 차변 | 대변 |
|---|---|
| 임차료 30만 원 | 예금 40만 원 |
| 전기요금 10만 원 | |

> **차변 합계 40만 원 = 대변 합계 40만 원**

계정 개수는 달라도 됩니다. **양쪽 금액 합계가 같아야 합니다.** 여러 계정으로 구성되는 이런 분개를 복합분개라고 합니다.

이미 비용과 미지급 의무를 기록했다면 지급 시에는 해당 부채를 줄여야 합니다. 비용을 다시 기록하면 중복이 됩니다.

## 5. 차변·대변 규칙

| 계정 종류 | 증가 | 감소 |
|---|---|---|
| **자산** | 차변 | 대변 |
| **부채** | 대변 | 차변 |
| **자본** | 대변 | 차변 |
| **수익** | 대변 | 차변 |
| **비용** | 차변 | 대변 |

기본 계정의 방향이며, 감가상각누계액 같은 차감 계정은 별도 성격을 가집니다.

## 6. 분개·전표·전기·총계정원장의 관계

| 용어 | 역할 |
|---|---|
| **분개** | 어떤 계정의 차변·대변에 얼마를 기록할지 나타내는 회계 기록 |
| **전표** | 해당 회계 기록에 날짜·회사코드 등 정보를 담은 문서 |
| **전기** | 전표 내용을 회계 장부에 반영하는 처리 |
| **총계정원장** | 반영된 거래를 계정별로 관리하는 중심 장부 |

> **거래 이해 → 분개 → 전표 입력·전기 → 총계정원장 반영 → 잔액·재무제표 확인**

SAP에서 Journal Entry는 실제 회계 전표를 가리키는 표현으로도 사용됩니다. 위 구분은 개념을 이해하기 위한 설명이며, 용어가 항상 서로 독립된 SAP 객체를 뜻하는 것은 아닙니다.

## 7. SAP FI와 연결

SAP FI에서는 계정과 차변·대변 금액 등을 전표로 입력·전기하여 관련 계정에 반영합니다. 구매·판매 업무에서도 설정과 업무 처리에 따라 회계 전표가 자동 생성될 수 있습니다.

- 직접 입력: 거래 내용을 이해하여 계정과 차변·대변을 선택.
- 자동 생성: 업무 거래와 계정결정 설정 등을 통해 회계 기록 생성.
- 검토: 계정, 금액, 회사코드, 전기일, 거래 근거 등을 확인.

**차변·대변 합계가 같다는 것만으로 정확한 분개는 아닙니다.** 잘못된 계정이나 날짜로 기록해도 합계는 같을 수 있습니다.

## 8. 관련 용어

| 용어 | 뜻 |
|---|---|
| **계정** | 예금·급여처럼 회계 거래를 종류별로 기록하는 항목. 로그인 아이디와 다름 |
| **단순분개** | 차변과 대변에 각각 하나의 계정을 사용하는 분개 |
| **복합분개** | 차변 또는 대변에 여러 계정을 사용하는 분개 |
| **계정결정** | 업무 거래를 어떤 회계 계정으로 연결할지 정하는 규칙·설정 |

용어는 [통합 용어집](05-fi-glossary.md)에서도 확인할 수 있습니다.
