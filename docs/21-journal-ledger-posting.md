# 분개장·총계정원장·전기 한 번에 이해하기

## 1. 용어와 흐름

| 용어 | 역할 |
|---|---|
| 분개 | 계정·차변·대변·금액 결정 |
| 분개장 | 거래의 분개를 날짜순으로 기록 |
| 총계정원장 | 거래를 계정별로 모아 내역·잔액 관리 |
| 전기(轉記) | 분개 내용을 해당 원장 계정에 반영. 이전 기간인 전기(前期)와 다름 |

거래 → 증빙 확인 → 분개 → 분개장 → 원장 전기 → 잔액 → 시산표 → 결산수정·검증 → 재무제표.

## 2. 새싹회사 분개장

단위: 만 원. 기초 잔액 0, 세금·감가상각 생략, 출자 전액 자본금 가정.

| 참조 | 날짜 | 차변 | 대변 | 적요 |
|---|---|---|---|---|
| J01 | 10/1 | 보통예금 1,000 | 자본금 1,000 | 출자 |
| J02 | 10/2 | 보통예금 500 | 차입금 500 | 은행 차입 |
| J03 | 10/3 | 장비 300 | 보통예금 300 | 장비 구입 |
| J04 | 10/5 | 매출채권 200 | 서비스매출 200 | 외상 서비스 |
| J05 | 10/10 | 급여 80 | 보통예금 80 | 당기 급여 지급 |
| J06 | 10/15 | 보통예금 150 | 매출채권 150 | 채권 일부 회수 |

차변·대변 거래금액 합계는 각각 **2,230**입니다. 적요는 짧은 거래 설명, 참조번호는 기록 연결을 위한 번호입니다.

## 3. 전기의 규칙

**분개장 차변 → 해당 계정 원장 차변. 분개장 대변 → 해당 계정 원장 대변.**

J03을 전기하면 장비 계정 차변 300, 보통예금 계정 대변 300입니다. 날짜·금액·적요·참조를 연결하며 차변·대변을 뒤집지 않습니다.

## 4. 보통예금 원장

| 날짜 | 참조 | 내용 | 차변 | 대변 | 잔액 |
|---|---|---|---:|---:|---|
| 10/1 | J01 | 출자 | 1,000 | — | 차변 1,000 |
| 10/2 | J02 | 차입 | 500 | — | 차변 1,500 |
| 10/3 | J03 | 장비 지급 | — | 300 | 차변 1,200 |
| 10/10 | J05 | 급여 지급 | — | 80 | 차변 1,120 |
| 10/15 | J06 | 채권 회수 | 150 | — | 차변 1,270 |
| 합계 | | | **1,650** | **380** | **차변 1,270** |

원장은 최종 잔액뿐 아니라 잔액이 형성된 거래 내역도 보여줍니다.

## 5. 매출채권과 나머지 계정

매출채권: J04 차변 200, J06 대변 150 → **차변 잔액 50**. 회수한 150을 수익으로 다시 기록하지 않습니다.

| 계정 | 차변 합계 | 대변 합계 | 잔액 |
|---|---:|---:|---|
| 장비 | 300 | 0 | 차변 300 |
| 차입금 | 0 | 500 | 대변 500 |
| 자본금 | 0 | 1,000 | 대변 1,000 |
| 서비스매출 | 0 | 200 | 대변 200 |
| 급여 | 80 | 0 | 차변 80 |

총계정원장이라는 별도 계정은 없으며 여러 계정의 기록을 모은 장부입니다.

## 6. 잔액시산표

| 계정 | 차변잔액 | 대변잔액 |
|---|---:|---:|
| 보통예금 | 1,270 | — |
| 매출채권 | 50 | — |
| 장비 | 300 | — |
| 차입금 | — | 500 |
| 자본금 | — | 1,000 |
| 서비스매출 | — | 200 |
| 급여 | 80 | — |
| 합계 | **1,700** | **1,700** |

분개장 거래금액 합계 2,230과 잔액 합계 1,700은 다른 개념입니다. 합계 일치만으로 거래 누락·잘못된 계정 선택 등 모든 오류가 배제되지는 않습니다.

## 7. 재무제표 연결

추가 조정이 없다는 사례 가정에서:
- 손익: 서비스매출 200 − 급여 80 = 이익 120.
- 자산: 보통예금 1,270 + 매출채권 50 + 장비 300 = 1,620.
- 부채 500, 자본 1,000 + 이익 120 = 1,120.
- **자산 1,620 = 부채 500 + 자본 1,120**.

실제 결산은 감가상각·미지급비용 등 필요한 수정과 검증을 거칩니다.

## 8. SAP 연결

회계 전표를 전기하면 계정별 내역·잔액에 반영됩니다. 수기 학습처럼 사람이 같은 거래를 각 원장에 다시 중복 입력하는 방식은 아닙니다. 임시 저장·보류와 실제 전기는 구분합니다.
