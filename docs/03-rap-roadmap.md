# RAP 학습 순서

1. **ABAP 기초**: 데이터 타입 → 내부 테이블 → ABAP SQL → 클래스·인터페이스 → 예외 처리
2. **개발 환경**: ADT → 패키지 → ABAP Cloud 개발 제약·공개 객체
3. **CDS**: View Entity → Association → Composition → 금액·통화 의미 정의 → DCL 조회 권한
4. **RAP 구조**: Root·Child Entity → Interface·Projection → Behavior Definition·Implementation → Managed·Unmanaged 개념
5. **서비스 노출**: Service Definition → Service Binding → OData → Fiori elements 조회 화면
6. **기본 트랜잭션**: 생성·수정·삭제 → EML → 저장 흐름·트랜잭션 경계
7. **업무 로직**: Determination → Validation → Action → 메시지·실패 처리
8. **사용자 입력 관리**: Draft → 잠금 → ETag → 동적 필드·액션 제어 → 변경 작업 권한
9. **FI 조회 실습**: 공급업체 미결항목 → 필터·검색 → 금액·통화 표시 → 권한 확인
10. **지급요청 앱**: 요청 헤더·항목 → 입력·저장 → 금액 검증 → 승인요청·상태 변경
11. **표준 FI 연계**: SAP 버전·환경 확인 → 지원되는 공개 API 확인 → RAP 트랜잭션 호환성 → 회계 처리 호출 → 오류·중복 처리
12. **품질 검증**: SQL·CDS 성능 → ATC → ABAP Unit·RAP 테스트 → 권한·잠금·API 실패 시나리오
