# FI 학습 순서

1. **[회계 기초](04-accounting-basics.md)**: 자산·부채·자본·수익·비용 → 차변·대변 → 분개
2. **SAP 회계 구조**: 회사코드 → 계정과목표 → G/L 계정 → 전표 헤더·항목 → 전표일·전기일 → 회계연도·전기기간 → 전표유형
3. **GL**: 전표 입력 → 계정별 항목 조회 → 잔액 조회 → 조정계정 → 재무제표 연결
4. **AP·AR**: 거래처 마스터 → 송장·청구 → 지급조건·만기일 → 미결항목 → 지급·입금 → 반제 → 부분지급·잔액항목
5. **TAX**: 과세표준 → 세금코드 → 매입·매출 세금 → 공제·불공제 → 원천세
6. **AA**: 자산클래스 → 자산 마스터 → 감가상각영역·내용연수·감가상각키 → 취득 → 감가상각 → 장부가액 → 이전·처분
7. **결산**: 감가상각 전기 → 외화평가 → 미지급·선급 비용 → 잔액 확인 → 전기기간 마감 → 재무제표
8. **자금 업무 연결**: 지급 예정 → 지급 실행 → 은행 내역 대사
9. **개발 연결**: FI 전표·데이터 구조 → CDS → 지원 API → [RAP 학습](03-rap-roadmap.md)
