# 회계관리 2급 학습 순서 — 2026년판 기준

**목표: 삼일회계법인 회계관리 2급 회계원리 학습.**

삼일의 공식 『회계관리2급 회계원리(2026)』 목차를 참고하여 이해와 문제풀이에 맞게 재구성했습니다. 아래는 공식 목차의 복제가 아닌 학습 순서입니다. 2025년판 대비 개정 차이를 모두 확인했다는 의미는 아닙니다. 시험 적용 공지·교재 정오표는 공식 안내를 함께 확인합니다.

## 1. 회계와 재무제표의 기초

1. **회계의 목적**: 회사의 거래 → 회계정보 → 정보 이용자.
2. **재무제표의 종류와 관계**: 재무상태표 → 손익계산서 → 자본변동표·현금흐름표·주석의 역할 → 서로 연결되는 금액.
3. **회계의 다섯 요소**: [자산·부채·자본·수익·비용](04-accounting-basics.md) → 회계등식.
4. **기록 방향**: [차변·대변](06-debit-credit.md) → 계정별 증가·감소.
5. **거래 기록**: [분개](07-journal-entry.md) → 분개장 → 총계정원장 전기.
6. **회계 흐름 미리 보기**: 거래 → 분개 → 전기 → 시산표 → 결산수정 → 재무제표.

연습: 거래에서 계정을 고르고 분개한 뒤 계정별 잔액을 계산합니다.

## 2. 계정별 회계 처리

7. **유동자산**: 현금·예금 → 채권과 회수 → 회수 불확실성 → 재고와 매출원가 → 기타 단기 자산.
8. **비유동자산**: 장기 보유 자산 → 유형자산 취득·감가상각·처분 → 무형자산 등.
9. **부채**: 단기·장기 의무 구분 → 외상채무·차입금 → 발생한 미지급 의무 → 선수령 거래.
10. **자본**: 출자 → 자본금과 관련 자본 항목 → 누적 이익 → 배당 및 자본 변동.
11. **수익**: 수익 금액과 인식 시점 → 영업에서 발생한 수익과 그 밖의 수익.
12. **비용과 이익**: 원가·비용 구분 → 판매된 재고의 원가 → 영업비용 및 기타 비용 → 법인세비용 → 순이익.

연습: 각 거래의 분개와 재무제표 영향을 함께 설명합니다. 법인세비용 학습을 1급 세무회계 전체 학습으로 확대하지 않습니다.

## 3. 결산과 재무제표 작성

13. **결산 절차**: 기간 말에 조정하는 이유와 순서.
14. **시산표**: 작성 → 차변·대변 확인 → 합계로 발견할 수 없는 오류 구분.
15. **결산수정분개**: 선급·미지급·미수·선수 → 감가상각 등 계정별 조정.
16. **장부 마감과 이월**: 수익·비용 결과 정리 → 재무상태표 계정 잔액 이월.
17. **종합 사례**: 수정 전 잔액 → 조정 → 재무제표 완성.

연습: 문제의 기말 자료를 이용해 수정분개와 최종 잔액을 계산합니다.

## 4. 재무제표 해석

18. **재무제표 확인**: 실제 보고서 구성과 필요한 정보 찾기.
19. **감사의견**: 의견의 종류와 의미 구분.
20. **재무상태·성과 읽기**: 자산·채무 구성 → 수익성 → 재무제표 관계.
21. **비율 분석 보충**: 비율 계산 → 의미와 비교의 한계. 2026년 교재의 심화 내용을 참고합니다.

## 5. 시험 대비 반복

22. **단원별 문제**: 개념 확인 → 분개 → 금액 계산 → 오답 원인 기록.
23. **종합 문제**: 계정별 처리와 결산을 섞어 연습.
24. **공식 공개 문제·모의고사**: 현행 시험 안내에 맞춰 시간 제한 연습.
25. **최종 복습**: 반복 오답 → 계정 선택 실수 → 차변·대변 → 기간 귀속 → 계산 실수.

## 현재 위치와 다음 학습

- 지금까지 배운 자산·부채·자본·수익·비용, 차변·대변, 분개는 다시 활용합니다.
- **다음: 재무제표의 종류와 상호관계.**
- 이후 거래를 분개장·총계정원장으로 옮기는 연습을 하고 계정별 회계로 진행합니다.
- 기존 SAP 회사코드·CDS·RAP 자료는 [SAP FI 보조 학습](02-sap-fi-supplement-roadmap.md)으로 연결합니다. 회계 개념을 먼저 이해한 뒤 SAP 예시를 짧게 덧붙입니다.
- 새 용어는 [통합 용어집](05-fi-glossary.md)에 모읍니다. 필요한 분개·기간 흐름은 이미지로 설명합니다.
