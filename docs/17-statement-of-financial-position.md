# 재무상태표 쉽게 이해하기

**학습 흐름**: [회사의 거래](14-business-transactions.md) → [회계정보](15-accounting-information.md) → 재무상태표 → 손익계산서.

## 1. 뜻과 시간 기준

**재무상태표**는 특정 시점의 자산·부채·자본을 보여주는 보고서입니다. 한 시점의 사진으로 생각하면 쉽습니다.

- **자산**: 회사가 통제하는 경제적 자원.
- **부채**: 경제적 자원을 이전해야 하는 현재 의무.
- **자본**: 자산에서 부채를 차감한 잔여 지분.

“2026년 12월 31일 현재”처럼 날짜를 표시합니다. 일정 기간의 수익·비용을 보여주는 손익계산서와 구분합니다.

## 2. 회계등식

**자산 = 부채 + 자본**

은행 차입 400과 주주 출자 600으로 현금 1,000을 마련했다면 자산 1,000 = 부채 400 + 자본 600입니다. 자본은 통장에 따로 있는 돈이 아닙니다.

현금 300으로 장비를 사면 현금은 700, 장비는 300이 됩니다. 자산의 종류가 바뀌며 자산 총액은 그대로입니다.

## 3. 새싹회사 재무상태표

단위: 만 원. 출자액 전부를 자본금으로 처리하며 세금·감가상각 등을 생략한 학습 사례입니다.

거래: 출자 1,000 → 차입 500 → 장비 현금 구입 300 → 서비스 외상 제공 200 → 당기 급여 지급 80.

| 구분 | 항목 | 금액 |
|---|---|---:|
| 자산 | 현금 | 1,120 |
| | 매출채권 | 200 |
| | 장비 | 300 |
| | **자산 합계** | **1,620** |
| 부채 | 차입금 | 500 |
| | **부채 합계** | **500** |
| 자본 | 자본금 | 1,000 |
| | 이익잉여금에 반영되는 당기 이익 | 120 |
| | **자본 합계** | **1,120** |
| | **부채·자본 합계** | **1,620** |

현금 = 1,000 + 500 − 300 − 80 = 1,120.
이익 = 수익 200 − 비용 80 = 120.

다른 자본 변동이 없는 이 사례에서 기말자본은 기초 출자자본 1,000에 이익 120을 더한 1,120입니다. **손익계산서의 이익이 자본 증가로 연결됩니다.**

## 4. 유동·비유동 구분

| 구분 | 이해 방법 | 예시 |
|---|---|---|
| 유동자산 | 정상영업주기에 현금화·판매·소비하거나 12개월 내 회수하는 자산 등 | 현금, 매출채권, 재고 |
| 비유동자산 | 유동자산으로 분류되지 않는 자산 | 장기 사용 건물·기계, 장기투자 |
| 유동부채 | 정상영업주기 또는 가까운 기간에 결제할 의무 등 | 매입채무, 미지급비용, 단기차입금 |
| 비유동부채 | 유동부채로 분류되지 않는 부채 | 요건을 충족하는 장기차입금 등 |

1년 기준만으로 모든 항목을 판단하지 않습니다. 정상영업주기, 거래 목적, 현금 사용 제한, 보고일 현재 결제를 연기할 권리 등을 적용 기준에 따라 확인합니다.

**정상영업주기**는 영업에 필요한 자산 취득부터 판매·현금 회수까지의 기간입니다. 원래 5년 대출이라도 보고일 현재 6개월 뒤 상환할 부분은 유동부채로 분류될 수 있습니다.

**재고자산**은 판매할 상품·제품이나 생산에 사용할 원재료 등입니다. **유형자산**은 물리적 형태가 있고 영업에 장기간 사용하는 자산입니다.

## 5. 거래별 변화

| 거래 | 자산 | 부채 | 자본 |
|---|---|---|---|
| 현금 100 차입 | +100 | +100 | 변화 없음 |
| 현금 100으로 장비 구입 | 현금 -100, 장비 +100 | 변화 없음 | 변화 없음 |
| 차입금 원금 100 상환 | -100 | -100 | 변화 없음 |
| 서비스 제공 후 현금 100 수령 | +100 | 변화 없음 | 수익을 통해 +100 |
| 당기 급여 30 발생·지급 | -30 | 변화 없음 | 비용을 통해 -30 |
| 기존 매출채권 100 회수 | 현금 +100, 매출채권 -100 | 변화 없음 | 변화 없음 |

자산 증가가 항상 이익은 아닙니다. 매출채권 회수 시 수익을 중복 인식하지 않습니다.

## 6. 읽는 순서와 주의점

1. **자산 구성**: 현금, 매출채권, 재고 등에 얼마나 배분되어 있는지 확인.
2. **부채 만기**: 곧 갚을 금액과 현금 마련 가능성 확인.
3. **자본 구성**: 출자금과 누적 이익·손실 구분.
4. **전기 비교**: 지난해와 비교하여 증가·감소 원인 확인.

자산이 많아도 현금이 부족할 수 있습니다. 자본 장부금액은 주식시장 가치나 회사 매각가격과 같지 않습니다. 회계등식의 일치만으로 모든 기록이 정확하다고 판단할 수도 없습니다.

- 자본은 별도 현금인가? → **아니요. 자산 − 부채입니다.**
- 장비 현금 구입으로 자산 총액이 반드시 줄어드나? → **위 사례에서는 자산 종류만 바뀝니다.**
