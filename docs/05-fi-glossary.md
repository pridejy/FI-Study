# 회계·SAP FI 용어집

회계 및 SAP FI 학습 중 등장하는 용어를 이 파일에 모아 관리합니다.

## 1. 장부와 전표

| 용어 | 뜻 | 예시·SAP 연결 |
|---|---|---|
| 총계정원장 (General Ledger, G/L) | 회사의 회계 거래를 계정별로 분류하여 거래 내역과 잔액을 관리하는 중심 장부 | 현금·채무·매출·비용 등의 계정으로 구성. SAP FI-GL에서 관리 |
| G/L 계정 | 총계정원장 안에서 특정 종류의 거래를 기록하는 개별 계정 | 예금, 매출, 급여. 계정번호·명칭 등은 회사의 설정에 따라 다름 |
| 계정과목 | 거래를 회계 성격별로 구분하는 항목 | 현금·매입채무·매출 등. SAP에서는 G/L 계정으로 구체화 |
| 계정과목표 (Chart of Accounts) | 사용하는 G/L 계정들의 목록과 구조 | 장부 자체나 거래 내역과는 다름 |
| 분개 (Journal Entry) | 거래를 어느 계정의 차변·대변에 얼마로 기록할지 정하는 회계 기록 | 차변 소모품비 / 대변 예금 |
| 차변 (Debit) | 분개의 왼쪽 | 기본적으로 자산·비용 증가 방향 |
| 대변 (Credit) | 분개의 오른쪽 | 기본적으로 부채·자본·수익 증가 방향 |
| 회계 전표 (Accounting Document) | 회계 거래의 계정·금액·날짜 등을 담은 기록 단위 | SAP에서 헤더와 항목으로 구성 |
| 전표 헤더 | 전표 전체에 공통으로 적용되는 정보 | 회사코드·전표일·전기일 등 |
| 전표 항목 | 개별 계정과 금액 등에 관한 정보 | 예금 항목, 비용 항목 등 |
| 전기 (Posting) | 거래를 회계 장부에 반영하는 처리 | 전표를 저장·전기하여 계정 내역과 잔액에 반영 |
| 잔액 (Balance) | 특정 시점까지의 거래를 반영한 계정의 남은 금액 | 예금 입금 100, 출금 30이면 잔액 70 |
| 보조원장 (Subledger) | 거래처·자산 등 대상별 상세 거래를 관리하는 장부 | AP 공급업체별, AR 고객별, AA 자산별 |
| 조정계정 (Reconciliation Account) | 보조원장 거래를 GL에 연결하는 G/L 계정 | 공급업체 전기 시 관련 채무 조정계정에도 반영 |
| 시산표 (Trial Balance) | 계정별 차변·대변 합계 또는 잔액을 모아 확인하는 표 | 합계 일치는 점검 수단이며 모든 오류가 없다는 증거는 아님 |

[차변·대변의 쉬운 설명과 거래 예시](06-debit-credit.md)

## 2. 재무제표와 기본 요소

| 용어 | 뜻 | 예시 |
|---|---|---|
| 재무상태 (Financial Position) | 특정 시점의 자산·부채·자본 구성 | 12월 31일 현재 회사가 가진 자원과 의무 |
| 재무제표 (Financial Statements) | 회사의 재무상태·성과·현금흐름 등을 체계적으로 보여주는 보고서 묶음 | 재무상태표, 손익·포괄손익 관련 보고서, 현금흐름표, 자본변동표, 주석 등 |
| 재무상태표 (Balance Sheet / Statement of Financial Position) | 특정 시점의 자산·부채·자본을 보여주는 재무제표 | 자산 = 부채 + 자본 |
| 손익계산서 (Income Statement / P&L Statement) | 일정 기간의 수익·비용과 이익·손실을 보여주는 보고서 | 월간 매출과 비용. 기타포괄손익 표시 방식 등은 적용 기준에 따라 확인 |
| 현금흐름표 (Statement of Cash Flows) | 일정 기간의 현금 유입·유출을 영업·투자·재무활동 등으로 보여주는 재무제표 | 대출 유입, 기계 구매 지출 등 |
| 자산 (Asset) | 과거 사건으로 회사가 통제하는 현재의 경제적 자원 | 예금·매출채권·기계 |
| 부채 (Liability) | 과거 사건으로 발생한 경제적 자원을 이전해야 하는 현재 의무 | 매입채무·차입금 |
| 자본 (Equity) | 자산에서 부채를 차감한 잔여 지분 | 통장에 따로 있는 현금이 아님 |
| 자본금 | 출자금 중 자본금으로 분류되는 금액 | 자본의 한 구성요소 |
| 이익잉여금 (Retained Earnings) | 이익 중 배당 등으로 유출되지 않고 누적된 금액 | 현금 잔액과는 다름 |
| 수익 (Income) | 소유주 출자 외에 자산 증가·부채 감소로 자본이 증가하는 항목 | 매출·이자수익 등. 입금과 다름 |
| 매출 (Revenue / Sales) | 통상적 영업활동에서 발생하는 수익 | 상품 판매·서비스 제공 |
| 비용 (Expense) | 소유주 분배 외에 자산 감소·부채 증가로 자본이 감소하는 항목 | 급여·임차료·감가상각비. 출금과 다름 |
| 이익·손실 (Profit / Loss) | 수익에서 비용을 차감한 결과 | 음수이면 손실 |
| 발생주의 (Accrual Basis) | 현금 수수 시점만이 아니라 거래·사건의 효과가 발생한 기간에 반영하는 회계 방식 | 이번 달 근무분 급여를 다음 달 지급해도 이번 달 비용 |
| 결산 (Closing) | 기간 말 조정·검증 등을 수행하고 재무보고를 준비하는 과정 | 감가상각·외화평가·기간 마감 등 |

## 3. 채권·채무·자산

| 용어 | 뜻 | 예시·SAP 연결 |
|---|---|---|
| 매출채권 | 영업 거래에서 고객에게 받을 대금에 대한 권리 | AR에서 상세 관리 |
| 매입채무 | 영업 거래에서 공급업체에 지급해야 할 채무 | AP에서 상세 관리 |
| 차입금 | 외부에서 빌려 상환 의무가 있는 자금 | 대출금 원금은 수익 아님 |
| 선급비용 | 미래 기간의 서비스를 받기 위해 먼저 지급한 금액 중 자산으로 남은 부분 | 미래 기간 보험료 |
| 미지급비용 | 비용이 발생했으나 아직 지급하지 않은 의무 | 미지급 급여 |
| 선수금·계약부채 | 먼저 대금을 받고 아직 공급 의무를 이행하지 않은 부분과 관련된 부채 | 거래 조건에 따라 구체적 분류 확인 |
| 고정자산 | 장기간 영업에 사용하는 자산을 가리키는 실무 용어 | 기계·건물 등. 모든 비유동자산과 동일한 뜻은 아님 |
| 감가상각 (Depreciation) | 감가상각대상금액을 내용연수에 걸쳐 체계적으로 배분하는 처리 | 자산 사용에 따른 비용 배분, 시장가격 하락과 동일하지 않음 |
| 감가상각누계액 | 지금까지 누적된 감가상각액 | 부채가 아니라 관련 자산의 차감 계정 |
| 장부가액 (Carrying Amount) | 장부에 인식된 자산 등의 금액 | 기계 취득원가에서 누적 감가상각·손상차손 등을 차감 |
| 내용연수 (Useful Life) | 회사가 자산을 사용할 것으로 예상하는 기간 또는 생산량 등 | 기계 예상 사용기간 |
| 잔존가치 (Residual Value) | 내용연수 종료 시 예상 상태에서 처분해 얻을 것으로 추정되는 금액에서 처분원가를 차감한 금액 | 감가상각 계산에 영향 |

## 4. SAP FI 공통·업무 용어

| 용어 | 뜻 | 연결 |
|---|---|---|
| FI (Financial Accounting) | SAP 재무회계 영역 | GL·AP·AR·AA 등 |
| FI-GL | 총계정원장 회계 | 계정·거래·잔액·재무보고 |
| FI-AP | 매입채무 회계 | 공급업체 송장·지급·반제 |
| FI-AR | 매출채권 회계 | 고객 청구·입금·반제 |
| FI-AA | 자산회계 | 개별 자산 취득·감가상각·처분 |
| 회사코드 (Company Code) | 개별 재무제표를 작성하는 기본 회계 조직 단위 | 전표와 회사별 회계 관리 |
| 회계연도 (Fiscal Year) | 회계 실적을 집계하는 연도 | 반드시 달력연도와 같지는 않음 |
| 전기기간 (Posting Period) | 전기일에 따라 거래가 반영되는 회계기간 | 기간 개방·마감으로 전기 통제 |
| 전표일 (Document Date) | 원본 문서 또는 거래 문서의 날짜 | 송장 작성일 등 |
| 전기일 (Posting Date) | 거래를 장부에 반영하는 날짜 | 회계기간 결정에 사용 |
| 전표유형 (Document Type) | 전표 성격을 구분하고 관련 규칙을 제어하는 설정 | 허용 계정 유형·번호범위 등 |
| 지급조건 (Payment Terms) | 지급기한·할인조건 등의 규칙 | 만기일 산정에 사용 |
| 만기일 (Due Date) | 지급·수금 기한 | 미결항목 지급 계획 |
| 미결항목 (Open Item) | 아직 반제되지 않은 항목 | 미지급 송장 등 |
| 반제 (Clearing) | 관련 차변·대변 항목을 연결하여 정산하는 처리 | 송장과 지급 연결. 부분지급 등에서는 미결항목이 남을 수 있음 |
| 세금코드 (Tax Code) | 관련 설정과 함께 세금 계산·전기를 제어하는 코드 | 국가·세금 종류별 처리 확인 |
| 원장 (Ledger) | SAP에서 회계기준 등 목적에 따라 회계 기록을 관리하는 구분 | 대표원장·비대표원장. 개별 G/L 계정과는 다름 |
| 재무제표 버전 (Financial Statement Version, FSV) | 계정들을 재무제표 항목으로 묶는 보고 구조 | 재무상태표·손익계산서 구성 |

## 5. 총계정원장 상세 예시

> **거래 → 분개·전표 → 계정별 기록(총계정원장) → 계정 잔액 → 재무제표**

총계정원장은 단순 합계표가 아니라 **계정별 거래 내역과 잔액을 관리하는 장부**입니다. G/L 계정은 이 장부를 구성하는 개별 기록 단위입니다.

기초 잔액 0원에서 주주가 100만 원 출자하고, 당월 소모품을 구매하여 즉시 사용한 대금 10만 원을 예금으로 지급했다고 가정합니다. 세금은 생략합니다.

| 전표 | 차변 | 대변 |
|---|---|---|
| 출자 | 예금 100만 원 | 자본금 100만 원 |
| 소모품 구매·사용 | 소모품비 10만 원 | 예금 10만 원 |

총계정원장에서 계정별로 보면:

| G/L 계정 | 차변 합계 | 대변 합계 | 잔액 |
|---|---:|---:|---|
| 예금 | 100만 원 | 10만 원 | 차변 90만 원 |
| 자본금 | 0원 | 100만 원 | 대변 100만 원 |
| 소모품비 | 10만 원 | 0원 | 차변 10만 원 |

이 기록으로 손익계산서에서는 비용 10만 원과 손실 10만 원을 확인합니다. 재무상태표에서는 자산 90만 원, 부채 0원, 해당 손실을 반영한 자본 90만 원이 됩니다.

### 보조원장과의 차이

공급업체 A에 70만 원, B에 30만 원의 매입채무가 있고 같은 조정계정에 연결되어 있다면:

- **AP 보조원장:** A·B 각각의 송장과 채무를 상세 관리.
- **GL:** 해당 매입채무 조정계정에 합계 100만 원이 반영되며 관련 항목도 조회 가능.
- **조정계정:** AP와 GL을 연결.

SAP는 보조원장 전기와 관련 GL 반영을 자동으로 연결합니다. 두 장부에 같은 거래를 사용자가 별도로 중복 입력하는 방식이 아닙니다.

| 증빙 | 거래의 내용과 금액 등을 확인하는 자료. 영수증·계약서·거래명세서 등 |
| 출자 | 소유자가 사업에 자금을 제공하여 지분을 형성하는 것. 매출 아님 |

| 정보이용자 | 회계정보를 보고 의사결정을 하는 사람이나 기관 |
| 내부정보이용자 | 경영자·부서 관리자 등 회사 운영을 위해 정보를 사용하는 내부 이용자 |
| 외부정보이용자 | 투자자·은행·공급업체 등 회사 외부의 이용자 |

| 채권·채권자 | 채권은 돈 등을 받을 권리, 채권자는 그 권리를 가진 사람 |
| 채무·채무자 | 채무는 돈 등을 지급해야 할 의무, 채무자는 그 의무를 가진 사람 |
| 일반목적 재무보고 | 특정 이용자의 개별 요구만을 위한 것이 아닌 재무보고. 주된 이용자는 현재·잠재적 투자자, 대여자 및 기타 채권자 |
| 재무회계 | 주로 외부 보고를 위해 재무상태·성과 등을 정리하는 회계 |
| 관리회계 | 내부의 계획·통제·의사결정을 지원하는 회계 |
| 세무회계 | 세법에 따라 과세소득·세액 등을 계산하는 회계 |
| 목적적합성 | 이용자의 판단에 영향을 줄 수 있는 정보의 특성 |
| 충실한 표현 | 경제적 현상을 완전하고 중립적이며 오류 없는 과정으로 표현하는 특성. 추정치가 없다는 뜻은 아님 |
| 비교가능성 | 기간 간·회사 간 공통점과 차이를 파악할 수 있는 특성 |
| 검증가능성 | 근거·방법을 통해 표현의 타당성을 확인할 수 있는 특성 |
| 적시성 | 판단에 필요한 때 정보를 제공하는 특성 |
| 이해가능성 | 정보를 명확하게 분류·표현하는 특성 |

| 유동부채·비유동부채 | 정상영업주기·12개월 내 결제 등과 결제 연기 권리를 고려해 구분하는 부채 |
| 정상영업주기 | 영업에 필요한 자산 취득부터 판매·현금 회수까지의 기간 |

| 순자산 | 자산에서 부채를 차감한 금액. 자본과 연결되며 별도 현금이 아님 |
