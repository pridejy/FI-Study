# 손익계산서 쉽게 이해하기

**학습 흐름**: [재무상태표](17-statement-of-financial-position.md) → 손익계산서 → 회계등식.

## 1. 의미와 기간

**손익계산서**는 일정 기간의 수익·비용과 이익 또는 손실을 보여주는 보고서입니다.

**수익 − 비용 = 이익 또는 손실**

재무상태표는 “12월 31일 현재”의 자산·부채·자본을, 손익계산서는 “1월 1일부터 12월 31일까지”의 경영성과를 보여줍니다.

## 2. 수익과 비용

**수익**은 소유자의 출자 외에 자산 증가·부채 감소로 자본을 증가시키는 항목입니다. 매출은 통상적인 영업활동에서 발생하는 수익이며, 수익에는 이자수익 등도 포함됩니다.

**비용**은 소유자에 대한 분배 외에 자산 감소·부채 증가로 자본을 감소시키는 항목입니다. 급여·임차료·광고선전비·매출원가·감가상각비·이자비용 등이 있습니다.

- 입금이 모두 수익은 아닙니다. 차입금은 부채, 출자금은 자본입니다.
- 출금이 모두 즉시 비용은 아닙니다. 장비 구입은 자산 취득, 차입금 원금 상환은 부채 감소입니다.
- 기존 매출채권 회수는 현금 증가·매출채권 감소이며 수익을 다시 기록하지 않습니다.

## 3. 새싹회사 사례

단위: 만 원. 세금·감가상각 등은 생략합니다.

| 거래 | 손익 영향 |
|---|---|
| 주주 출자 1,000 | 수익 아님 |
| 은행 차입 500 | 수익 아님 |
| 장비 현금 구입 300 | 구입액 전부를 즉시 비용 처리하지 않음 |
| 서비스 외상 제공 200 | 수익 200 |
| 당기 급여 지급 80 | 비용 80 |

| 손익계산서 항목 | 금액 |
|---|---:|
| 서비스 매출 | 200 |
| 급여 비용 | (80) |
| **당기순이익** | **120** |

괄호는 이 표에서 차감 금액을 뜻합니다. 당기순이익은 현재 회계기간의 최종 이익입니다.

## 4. 단계별 이익 계산

회계관리 2급 기초를 위한 전형적인 구조입니다. 실제 보고서의 명칭·구분은 적용 기준에 따라 확인합니다.

매출액 − 매출원가 = **매출총이익**
매출총이익 − 판매비와관리비 = **영업이익**
영업이익 + 영업외수익 − 영업외비용 = **법인세비용차감전순이익**
법인세비용차감전순이익 − 법인세비용 = **당기순이익**

별도 상품 판매 회사 예시(단위: 만 원):

| 항목 | 금액 |
|---|---:|
| 매출액 | 1,000 |
| 매출원가 | (600) |
| **매출총이익** | **400** |
| 판매비와관리비 | (250) |
| **영업이익** | **150** |
| 영업외수익 | 10 |
| 영업외비용 | (30) |
| **법인세비용차감전순이익** | **130** |
| 법인세비용 | (20) |
| **당기순이익** | **110** |

세금 20은 계산용 가정이며 특정 세율을 의미하지 않습니다. 급여 등은 담당 업무에 따라 매출원가 또는 판매비와관리비 등에 포함될 수 있습니다.

## 5. 매출원가와 재고자산

개당 원가 1만 원인 상품 10개를 구입하고 그중 6개를 개당 2만 원에 판매했다면:

- 매출액: 6개 × 2만 원 = 12만 원.
- 매출원가: 판매한 6개 × 1만 원 = 6만 원 → 손익계산서.
- 기말재고: 남은 4개 × 1만 원 = 4만 원 → 재무상태표.
- 매출총이익: 12 − 6 = 6만 원.

상품 구입액 전부가 곧바로 매출원가인 것은 아닙니다.

## 6. 이익과 현금의 차이

외상 서비스 200은 수익이지만 아직 현금 유입이 없습니다. 차입 500은 현금 유입이지만 수익이 아닙니다. 당기 근무분 급여를 다음 달 지급하더라도 당기 비용과 미지급 의무를 기록합니다. 이를 **발생주의**와 연결해 이해합니다.

## 7. 재무상태표 연결

새싹회사의 수익 200 − 비용 80 = 이익 120.
다른 자본 변동이 없는 사례에서 자본 1,000 + 이익 120 = 기말자본 1,120.

이익은 자본을 증가시키고 손실은 자본을 감소시킵니다. 출자·배당 등도 자본을 변화시키므로 자본 증가액이 항상 당기순이익은 아닙니다.

국제회계기준에는 당기손익 외에 기타포괄손익으로 구분하는 항목도 있습니다. 기본 손익 흐름을 익힌 후 별도로 학습합니다.

## 8. 확인 문제

- 대출금 수령은 매출인가? → **부채 증가입니다.**
- 매출총이익이 최종 이익인가? → **추가 비용 등을 반영해야 합니다.**
- 순이익은 통장 잔액인가? → **기간 성과와 현금 잔액은 다릅니다.**
