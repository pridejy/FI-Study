# 회사의 거래

**학습 흐름**: 회사의 거래 → [회계정보](15-accounting-information.md) → [정보이용자](16-accounting-information-users.md).

## 1. 회계에서 말하는 거래

**거래**는 자산·부채·자본 등 회계 요소에 변화를 일으키고 금액으로 측정할 수 있는 사건입니다. 사고파는 행위뿐 아니라 차입, 출자, 급여 발생, 자산 소실 등도 포함합니다.

| 사건 | 회계상 판단 | 이유 |
|---|---|---|
| 소유자가 회사에 출자 | 거래 | 현금과 자본 증가 |
| 은행에서 차입 | 거래 | 현금과 부채 증가. 수익 아님 |
| 업무용 장비 구입 | 거래 | 현금 감소·장비 증가. 지급액 전부가 즉시 비용인 것은 아님 |
| 서비스를 제공하고 나중에 대금 수령 | 거래 | 매출채권과 수익 발생 |
| 직원 근무에 따른 급여 발생 | 거래 | 지급 전이어도 비용과 미지급 의무 발생 가능 |
| 화재로 재고 소실 | 거래 | 자산 감소와 손실 발생 |
| 장비 구매 계획 | 계획만으로는 거래 아님 | 현재 회계 요소의 변화 없음 |

계약 체결만으로 언제나 자산·부채를 기록하는 것은 아닙니다. 계약 내용, 이행, 선지급·선수령 등을 살펴야 합니다.

## 2. 회사와 소유자의 재산 구분

**회계실체**는 회계 기록의 대상으로 구분한 단위입니다. 회사의 거래와 소유자 개인의 거래는 구분합니다. 소유자의 개인 주택은 회사 자산이 자동으로 되지 않습니다. 출자금은 매출이 아닙니다.

## 3. 현금 이동과 거래는 다름

서비스 200만 원을 제공하고 다음 달 받기로 했다면 매출채권과 수익이 발생합니다. 나중에 수금하면 현금이 늘고 매출채권이 줄며, 동일한 수익을 다시 기록하지 않습니다. 이는 현금 수수만을 기준으로 하지 않는 **발생주의**와 연결됩니다.

## 4. 새싹회사 공통 사례

단위: 만 원. 출자액 전부를 자본금으로 처리한다고 가정합니다.

| 거래 | 자산 변화 | 부채·자본 변화 |
|---|---|---|
| 출자 1,000 | 현금 +1,000 | 자본금 +1,000 |
| 은행 차입 500 | 현금 +500 | 차입금 +500 |
| 장비 현금 구입 300 | 현금 -300, 장비 +300 | 없음 |
| 서비스 외상 제공 200 | 매출채권 +200 | 수익으로 자본 +200 |
| 급여 지급 80 | 현금 -80 | 비용으로 자본 -80 |

최종 현금 1,120, 매출채권 200, 장비 300으로 자산은 1,620입니다. 부채 500, 자본 1,120이며 이익은 120입니다.

**자산 1,620 = 부채 500 + 자본 1,120**

## 5. 기록 흐름과 확인 문제

증빙 확인 → [분개](07-journal-entry.md) → 분개장 → 총계정원장 → 결산 → 재무제표.

- 차입금이 수익인가? **아니요. 상환 의무인 부채입니다.**
- 현금이 움직이지 않아도 거래인가? **매출채권 발생처럼 해당할 수 있습니다.**
- 출자금이 매출인가? **아니요. 소유자의 자본 제공입니다.**

SAP FI에서는 거래를 전표로 기록하고 계정별 내역과 잔액으로 집계합니다.
